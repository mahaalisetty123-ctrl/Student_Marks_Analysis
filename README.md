# Student Marks Analysis using Python & NumPy

## Description
A beginner-friendly Data Analytics project built using Python and NumPy.

## Features
- User Input
- Input Validation
- Average Marks
- Highest Marks
- Lowest Marks
- Pass & Fail Count
- Pass Percentage
- Top 3 Marks
- Students Below Average

## Technologies Used
- Python
- NumPy
- VS Code
